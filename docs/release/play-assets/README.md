# Play asset exports

- `nutrilens-x-play-icon-512.png`: exact 512×512 Play icon export.
- `nutrilens-x-feature-graphic-1024x500.png`: exact 1024×500 feature graphic.
- `nutrilens-x-feature-graphic-master.png`: retained high-resolution source.

The logo/feature sources were generated with the built-in image generation tool
using a NutriLens-specific flat emerald/lime brief, then exported mechanically to
the exact Play dimensions. Review them in Play Console's device-safe previews
before submission. These brand assets contain no custom model file or medical
claim.
