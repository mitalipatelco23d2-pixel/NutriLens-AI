# ADR-002 — Next.js web application

**Status:** Accepted

**Context:** The web experience needs responsive, typed React development.
**Decision:** Use Next.js with TypeScript and the App Router.
**Rationale:** Strong tooling, static/interactive rendering and accessible React ecosystem.
**Alternatives:** Vite SPA, Angular, Flutter Web.
**Consequences:** Server/client boundaries and framework upgrades require discipline.
