# ADR-006 — Neo4j food knowledge graph

**Status:** Accepted

**Context:** Food, ingredient, nutrient and evidence relationships require graph traversal.
**Decision:** Use Neo4j Community Edition.
**Rationale:** Expressive Cypher queries and accessible graph tooling.
**Alternatives:** RDF triplestore, PostgreSQL graph modelling.
**Consequences:** Community-edition limits and a separate graph model must be managed.
