# R3 supplemental real-image adapters

This versioned directory contains Git-ignored R2 `ImageManifestRecord` and `DetectionAnnotationRecord` outputs generated from the R3 public/research acquisitions. It supplements the completed R2 release without changing R2 history or architecture.

Regenerate the local payloads with the acquisition scripts in `scripts/data/r3/`, then run `verify_r3_image_datasets.py`. The tracked acquisition, annotation-status and evaluation manifests live outside this ignored payload directory.
